# AIVD 3.18 — Global Epistemic Budget Arbitration

## Research question

Can AIVD discover previously reachable unknown security behavior more
effectively when ALL discovery/investigation subsystems compete through a
single global epistemic experiment allocator, rather than consuming locally
owned sequential budgets?

This is **not** a new vulnerability-discovery algorithm. It is a pipeline-level
orchestration change. The episode budget remains **32**.

## Diagnosed 3.17 bottleneck (not retuned)

`UnknownsPipeline` partitions 32 slots *up front*:

```
axis_cap + invention_reserve + gate_reserve = 32
```

Then it spends them sequentially: smoke → residual sweep → axis trials →
invention/openworld leftover → gates.

Later branches inherit whatever earlier stages did not spend. Joint / autonomy /
reasoning each peel local reserves from that leftover. 3.16's
`tested_candidates=0` and 3.17's static 40% openworld floor are symptoms of
**local budget ownership**, not of missing scoring.

## Architecture

```
OBSERVE
  → GENERATE HYPOTHESES / CANDIDATES
  → REGISTER BRANCHES
  → SUBSYSTEMS PROPOSE EXPERIMENTS
  → GLOBAL EPISTEMIC ARBITER
  → EXECUTE ONE EXPERIMENT
  → OBSERVE RESULT
  → UPDATE MEMORY / HYPOTHESES / BRANCHES
  → RECOMPUTE PROPOSALS
  → repeat
  → VERIFY / REJECT / UNRESOLVED
```

Default `epistemic_mode=off` ≈ 3.17.

## Scoring (not greedy EIG)

Weights from `invention.scoring` + `RewardWeights`:

```
value = 0.30·IG + 0.10·ΔU + 0.20·disc + 0.35·sec + 0.10·ver
      + 0.30·(ΔP_completion · terminal_value) + 0.15·unlock
      − 0.25·cost − 0.20·red − 0.15·rep − 0.20·opportunity
```

`P(completion)` is generic (evidence, dead-end score, remaining steps vs
remaining budget). No holdout mechanism names.

## Soft protected floor

A branch *earns* protected continuation when evidence is causal or
behaviorally meaningful, uncertainty remains, a completion path is plausible,
and work is not a failed repeat. The floor is dynamic, revocable, and
subsystem-agnostic. It is **not** `if openworld: reserve 13`.

## Same-budget rule

Every environment interaction charges the global ledger.
`sum(experiment_costs) <= 32`. No hidden probes, no free retries.

## Shadow mode

`epistemic_shadow` records LEGACY vs ARBITER choice and still executes the
legacy pick. Authoritative mode (`epistemic_full` / `full_3_18`) executes the
arbiter pick.

## Success criterion

With the same 32-experiment budget, the arbiter should allocate more
effectively than the 3.17 sequential/local-reserve pipeline, avoid starving
promising multi-step branches, redirect after falsification, preserve
invisible controls, and be tested on a fresh holdout without holdout-specific
knowledge.
