## What's new in v3.18.0

**Global Epistemic Budget Arbitration** over 3.17:
all discovery subsystems propose experiments to one global allocator instead of
owning sequential leftover slots. Scoring uses expected branch-completion value
(not greedy EIG). Same 32-experiment budget. Config `epistemic_mode`
(default **off** ≈ 3.17). See `docs/3.18_global_epistemic_budget_arbitration.md`.
