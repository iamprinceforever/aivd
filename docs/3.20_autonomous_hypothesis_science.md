# AIVD 3.20 — Autonomous Hypothesis Science

Research question: can AIVD enter an unseen system with no vulnerability
signatures, no planted lexical hints, and no closed attack taxonomy, then
autonomously form hypotheses, design discriminating experiments, falsify
alternatives, reproduce, and emit a verified report — under the same
32-experiment budget?

3.19 owned the budget. 3.20 owns the *question*. Residual token replay is
not the search. Colon-labels in observations are not primitives. Newly
observed content is proposed first. Generic operators (omit, swap, wrap,
repeat, separate) compete as hypotheses.

Default `epistemic_mode=off` ≈ 3.19. `full_3_19` leftover-free episode
ownership is preserved. `full_3_20` runs the science loop.
